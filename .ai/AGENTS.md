## House rules

- The pattern itself is defined once, in `skills/kb/SKILL.md`; other skills link to it instead of restating it.
- Skills are English, short and imperative. A skill's `description` says what it does and when to trigger it.
- Keep each fact in one file here. When you learn something durable about the project, add it to the matching file in the same change.
